# Pygame and OOP Learning Project

## Objective
This project was developed to explore and practice the basics of **Pygame** and **Object-Oriented Programming (OOP)** principles, such as classes and objects. The goal is to provide a hands-on approach to learning how to structure a game using OOP concepts, helping developers understand how to organize code efficiently for larger projects.

## Features
- **Pygame Framework**: Learn how to utilize Pygame for game development, handling game loops, events, rendering, and more.
- **Object-Oriented Programming**: Create classes for different game entities (e.g., player, enemies, obstacles) and manage their interactions.
- **Customizable Game Objects**: Each object in the game has its own properties and behaviors, demonstrating the power of OOP for creating complex systems.

## How It Works
The project follows **OOP principles** by organizing the code into separate classes for each game object or component. This includes:

- **Player Class**: Manages player movement, collision detection, and user input.
- **Enemy Class**: Handles the behavior of enemies in the game world.
- **Game Loop**: The main loop processes input, updates the game state, and renders the graphics on the screen using Pygame.
By breaking the code into individual classes, the project demonstrates how OOP helps create modular, reusable code.

## Learning Objectives
- Understand the basics of **OOP**: encapsulation, inheritance, and polymorphism.
- Use **Pygame** to handle graphics, input, and events in a game development context.
- Build a simple game structure by applying OOP techniques to manage game objects.
